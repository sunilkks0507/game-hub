# game-hub

Offline-first PWA game hub: small thinking games for children and adults. No ads, no accounts, no tracking.

## Status
Planning and first game in progress.

| Game | Category | Status |
|---|---|---|
| Chaturanga (ancient Indian chess) | Adults, Challengers, Family | Playable (v0.1.0) |
| Pallanguzhi (seed-sowing game) | Explorers, Challengers, Family | Playable (v0.1.0), rule set to confirm |

## Docs
- `AGENTS.md`: rules for working in this repo
- `DECISIONS.md`: settled choices
- `DESIGN_SYSTEM.md`: shared tokens and layout rules
- `GAME_ONBOARDING_STANDARD.md`: what every game ships with
- `src/games/chaturanga/`: game brief and master spec
- `src/games/pallanguzhi/`: game brief and master spec

## Principles
Works offline after the first load. Free only. Collects no personal data. Original art and synthesised sound. Pure rules logic with unit tests.
